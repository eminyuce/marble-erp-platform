Sistem Araçları içindeki Deployment ekranı, sunucuya SSH açmadan main dalından üretim yayını başlatır ve çıktıyı canlı gösterir.

Ne çalışır

  • git pull origin main yeni kodu çeker.
  • ./scripts/deploy_production.sh -y derler, servisi durdurur, JAR’ı değiştirir ve sağlık kontrolü yapar.
  • Yayın sırasında uygulama kısa süre kapanır; bu sekme açık kalırsa günlük otomatik devam eder.

İlk kurulum

  • Bu ekran yalnızca Linux üretim sunucusunda ve yönetici hesabıyla çalışır.
  • İlk kez SSH ile sudo ./scripts/deploy_production.sh -y çalıştırın; bu, sonraki yayınlar için şifresiz sudo ve yayın komutunu kurar.
  • Düğme kapalıysa sarı kutudaki nedeni okuyun.

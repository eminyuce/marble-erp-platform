Bu Sayfa Ne İşe Yarar? Linux sunucusuna harici terminal veya SSH açmaya gerek kalmadan; sistemin en güncel yazılım kodunu tek tıkla çekip derleyen, test eden ve canlıya alan sistem yöneticisi yayın konsoludur.

Bu Sayfada Ne Yapabilirsiniz?

  • Canlı sunucuda çalışan güncel yazılım sürümünü ve Git commit numarasını görebilirsiniz.
  • GitHub üzerindeki onaylanmış en son yazılım güncellemelerini tek tıkla canlıya alabilirsiniz.
  • Derleme, otomatik test ve servis yeniden başlatma adımlarını canlı konsol ekranından izleyebilirsiniz.
  • Yayın sonrası sistemin ayakta olduğunu (Health Check) doğrulayabilirsiniz.

Bu Buton Ne İşe Yarar?

  • Üretim Yayınını Başlat: Sunucu üzerinde güncelleme betiğini (./scripts/deploy_production.sh -y) güvenli şekilde tetikler.
  • Canlı Konsol Akışı: Arka planda yürütülen Maven derlemesi ve sistem kontrollerinin anlık loglarını gösterir.

Adım Adım Üretim Yayını Nasıl Yapılır?

  1. Ekrandaki mevcut aktif sürüm bilgisini kontrol edin.
  2. Sağ üstteki "Üretim Yayınını Başlat" butonuna tıklayın.
  3. Konsol akışında otomatik yürütülen adımları izleyin:
    • git fetch origin main ve git reset --hard origin/main: Sunucu kopyasını GitHub’daki son main ile eşitler. Yerel değişiklikler yayın sırasında silinir.
    • Maven ile projeyi derler ve otomatik testleri çalıştırır.
    • Eski servisi kapatıp yeni JAR dosyasını ayağa kaldırır.
    • Veritabanı ve web servisinin ayakta olduğunu doğrular.
  4. Akışın sonunda yeşil "Başarılı / Aktif" ibaresi çıktığında yayın tamamlanmıştır.
Gerçek Kullanım Örneği:
Yazılım ekibi ERP'ye yeni bir raporlama özelliği eklediğinde, sistem yöneticisi mesai bitiminde veya vardiya değişiminde bu sayfaya girip "Üretim Yayınını Başlat" butonuna basar. Sistem 40 saniye içinde tüm testleri tamamlayıp yeni sürümü kesintisiz olarak canlıya alır.
Kritik Güvenlik Kuralı:
Yeni sürüm devreye girerken web servisi yaklaşık 15–30 saniye yeniden başlar. Bu nedenle yayının ocak ve fabrika vardiya değişim saatlerinde veya sakin saatlerde yapılması tavsiye edilir.

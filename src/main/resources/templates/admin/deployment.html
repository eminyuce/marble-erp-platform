Yeni Gelişmeleri Sahaya Taşı / Üretim Yayını

Yazılım ekibinin gönderdiği son sürüm GitHub Actions ile Docker Hub imajına dönüşür. Bu düğme o imajı sunucuya indirir ve uygulamayı yeniden başlatır.

Sunucuda kod derlenmez. Çalışan komutlar: docker compose pull ve docker compose up -d

Sistem Araçları

İmaj

Docker Hub
Etiket
main dalına her gönderimde yalnızca latest etiketi güncellenir.
Durum
Başlangıç
Bitiş

Ne olur?

  1. Kod main dalına geçince GitHub Actions imajı Docker Hub’a yükler.
  2. Düğme bu imajı indirir. Sunucuda Maven veya npm çalışmaz.
  3. Uygulama konteyneri yeni imajla değişir. Kısa kesinti olur. Veritabanındaki kayıtlar silinmez.
  4. Sağlık kontrolü tamamlanınca ekran yeniden bağlanır.

Bu sekme açık kalsın. Konteyner yenilenince bağlantı kopar; ekran yeniden bağlanıp kalan günlüğü gösterir.

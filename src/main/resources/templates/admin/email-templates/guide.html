1. Şablon Adı KEY

E-Posta Motoru Çalışma Prensibi & Güvenlik Kuralları

  • XSS Koruması: Gönderilen tüm model alanları (müşteri adı, notlar vb.) varsayılan olarak HTML-escape işlemine tabi tutulur. Kullanıcıdan gelen zararlı script kodları e-posta istemcilerinde çalışamaz.
  • SMTP Header Injection Koruması: Konu satırındaki (subject) tüm satır sonu ve taşıyıcı dönüş (CR/LF) karakterleri otomatik olarak temizlenir.
  • Güçlü Tipli Java Modelleri: Her e-posta için BaseEmailModel arayüzünü uygulayan bir Java sınıfı mevcuttur. emailService.sendTemplatedEmail(to, model) metoduyla tek satırda gönderim yapılabilir.
  • Önizleme Güvencesi: Bir şablon değiştirildiğinde veya yayına alınmadan önce mutlaka önizleme sayfasından canlı test gönderimi yapılmalıdır.
